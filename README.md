# Библиотека экспертизы ВЭШ

Каталог статей, кейсов, записей мастер-классов и демо-курсов Высшей экономической школы с поиском, фильтрами по темам и преподавателям и сбором подборок в PDF и для письма.

## Данные

Текущая версия содержит снимок единой базы Buildin от 27 октября 2026 года: 230 материалов — 82 статьи, 18 кейсов, 110 записей прошедших мастер-классов и 20 демо-курсов. Источники: [блог ВЭШ](https://veshk.ru/blog), [каталог мастер-классов](https://mk.veshk.ru/) и [демо-курсы](https://lk.veshk.ru/demo). Для 13 старых мастер-классов сохранены прямые ссылки на Rutube из каталога. Будущие вебинары исключены. Темы приведены к единому списку; преподаватели и спикеры указаны по источникам. Название вебинара Альпины и Borjomi уточнено по странице мероприятия: в карточке каталога ошибочно указана тема KPI.

`data.js` содержит выгрузку таблицы. Связанные таблицы не используются. Автоматическая синхронизация Buildin пока не подключена; изменение таблицы не обновляет этот снимок автоматически.

## Использование

Выберите один или несколько типов, тем и преподавателей. «Все» снимает ограничения по типу; повторное нажатие на тип отменяет его выбор. Внутри одной группы действует «или», между группами — «и». Добавьте найденные материалы в подборку, задайте название и вступление, затем нажмите «Сохранить PDF». Кнопка «Скопировать для письма» копирует название, вступление и нумерованный список с кликабельными названиями. Раскройте «Предпросмотр текста для письма», чтобы увидеть результат. Изменения названия, вступления и состава сразу попадают в предпросмотр и оба варианта экспорта.

В буфер одновременно записываются HTML с встроенным оформлением и обычный текст с полными URL. Вставляйте обычным Ctrl+V / ⌘V в редактор письма с форматированием: вставка без форматирования или режим простого текста удаляет оформление. Шрифты для письма стандартные (Arial), без зависимости от файлов сайта. Если Clipboard API недоступен, используется копирование через событие copy; при отказе браузера можно скопировать из предпросмотра вручную. Письма автоматически не отправляются.

Выбор сохраняется локально в браузере. PDF формируется на устройстве, содержит текст, встроенные фирменные шрифты и кликабельные ссылки на исходные публикации. В каждой строке PDF указаны только тип и кликабельное название материала. На странице размещается не более 8 материалов; длинное вступление может уменьшить их число на первой странице. Полные тексты статей в PDF не включены.

## Запуск и публикация

Сайт статический, сборка не требуется:

```sh
python3 -m http.server 8769
```

GitHub Pages публикует корень ветки `main`. Все ресурсы используют относительные пути. Данные и файлы для экспорта доступны без внешних CDN.

## Файлы

- `index.html`, `styles.css`, `app.js` — интерфейс и фильтры.
- `data.js` — текущий снимок базы.
- `pdf-export.js` — вёрстка PDF.
- `export-assets.js` — шрифты и логотип для PDF.
- `assets/` — фирменные ресурсы и jsPDF 4.2.1 (MIT, лицензия в `jsPDF-LICENSE.txt`).

Логотип, фирменные ресурсы и материалы ВЭШ не распространяются под лицензией библиотеки jsPDF.
