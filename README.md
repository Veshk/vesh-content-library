# Библиотека экспертизы ВЭШ

Каталог статей, кейсов, записей мастер-классов, демо-курсов и гайдов Высшей экономической школы с поиском, фильтрами по темам и преподавателям и сбором подборок в PDF и для письма.

## Данные

Текущая версия содержит снимок единой базы Buildin от 28 октября 2026 года: 233 материала — 82 статьи, 18 кейсов, 110 записей прошедших мастер-классов, 20 демо-курсов и 3 гайда. Источники: [блог ВЭШ](https://veshk.ru/blog), [каталог мастер-классов](https://mk.veshk.ru/), [демо-курсы](https://lk.veshk.ru/demo) и [папка гайдов](https://cloud.veshk.ru/s/g7MPx3oDdtFcect). Для 13 старых мастер-классов сохранены прямые ссылки на Rutube из каталога. Будущие вебинары исключены. Темы приведены к единому списку; преподаватели и спикеры указаны по источникам. Название вебинара Альпины и Borjomi уточнено по странице мероприятия: в карточке каталога ошибочно указана тема KPI.

Гайды ведут напрямую на публичные PDF в облаке ВЭШ. Названия взяты с обложек, темы определены по содержанию. В поле преподавателя оставлено пустое значение: авторы не указаны, а общий блок «Среди наших преподавателей» не подтверждает авторство. Исходные PDF не копируются в репозиторий.

`data.js` содержит выгрузку таблицы. Связанные таблицы не используются. Автоматическая синхронизация Buildin пока не подключена; изменение таблицы не обновляет этот снимок автоматически.

## Использование

Выберите один или несколько типов, тем и преподавателей. «Все» снимает ограничения по типу; повторное нажатие на тип отменяет его выбор. Внутри одной группы действует «или», между группами — «и». Добавьте найденные материалы в подборку, задайте название и вступление, затем нажмите «Сохранить PDF». Кнопка «Скопировать для письма» копирует название, вступление и материалы, сгруппированные по типу, как в PDF. В письме — обычный текст размером 11 pt, названия материалов и кликабельные ссылки действия. Группы выделены только полужирным, без линий, цветных заголовков и увеличенных шрифтов; преподаватели и темы в письмо не включаются. Раскройте «Предпросмотр текста для письма», чтобы увидеть результат. Изменения названия, вступления и состава сразу попадают в предпросмотр и оба варианта экспорта.

В буфер одновременно записываются HTML со встроенным простым оформлением и обычный текст с полными URL. Вставляйте обычным Ctrl+V / ⌘V в редактор письма с форматированием: вставка без форматирования или режим простого текста удаляет оформление. Шрифты для письма стандартные (Verdana, запасной Arial), без зависимости от файлов сайта. Если Clipboard API недоступен, используется копирование через событие copy; при отказе браузера можно скопировать из предпросмотра вручную. Письма автоматически не отправляются.

Выбор сохраняется локально в браузере. PDF формируется на устройстве, содержит текст, встроенные фирменные шрифты и кликабельные ссылки на исходные публикации. Материалы в PDF сгруппированы по типу: статьи, кейсы, мастер-классы, демо-курсы, гайды. Внутри группы сохраняется порядок добавления. Под кликабельным названием есть явная ссылка «Читать», «Смотреть запись», «Открыть демо-курс» или «Открыть гайд». Заголовок группы повторяется при переносе на следующую страницу. На странице размещается не более 8 материалов; длинное вступление может уменьшить их число на первой странице. Полные тексты статей в PDF не включены.

## Метки переходов

При создании PDF или копировании текста для письма ко всем экспортируемым ссылкам автоматически добавляются UTM-метки:

- `utm_source=vesh_library` — библиотека ВЭШ.
- `utm_medium=pdf` или `utm_medium=email` — формат подборки.
- `utm_campaign=selection_YYYY-MM-DD` — дата формирования подборки, например `selection_2026-10-28`.

Дата определяется заново при каждом экспорте по времени Екатеринбурга (`Asia/Yekaterinburg`) и фиксируется во всех ссылках одного файла или копирования. В готовой подборке дата не меняется при открытии в другой день. Названия ссылок остаются короткими; UTM находятся в их адресах. В обычном тексте копируются полные размеченные URL. Исходные параметры URL (например, Rutube `playlist`) и якоря `#video` сохраняются. Существующие значения этих трёх UTM заменяются, без дублирования. Данные Buildin и исходные URL в `data.js` не меняются.

## Запуск и публикация

Сайт статический, сборка не требуется:

```sh
python3 -m http.server 8769
```

GitHub Pages публикует корень ветки `main`. Все ресурсы используют относительные пути. Данные и файлы для экспорта доступны без внешних CDN.

## Файлы

- `index.html`, `styles.css`, `app.js` — интерфейс и фильтры.
- `data.js` — текущий снимок базы.
- `collection-format.js` — общие группы и подписи ссылок для PDF и письма.
- `pdf-export.js` — вёрстка PDF.
- `link-tracking.js` — общая разметка ссылок и дата формирования подборки.
- `export-assets.js` — шрифты и логотип для PDF.
- `assets/` — фирменные ресурсы и jsPDF 4.2.1 (MIT, лицензия в `jsPDF-LICENSE.txt`).

Логотип, фирменные ресурсы и материалы ВЭШ не распространяются под лицензией библиотеки jsPDF.
